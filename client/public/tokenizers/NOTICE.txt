clip.json
  OpenAI CLIP tokenizer vocabulary and BPE merges. The published JSON format
  was obtained from openai/clip-vit-base-patch32, commit
  3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268, and its 48,894 merges
  were checked against the original OpenAI CLIP BPE file:
  https://github.com/openai/CLIP/blob/main/clip/bpe_simple_vocab_16e6.txt.gz
  MIT; see LICENSE-CLIP-MIT.txt

These files are used locally in the browser for token counting. NovelAI's
client tokenizer definition files are not included in this release.
