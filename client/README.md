# NAI 工作台前端

React / TypeScript 浏览器客户端。Gate 部署时由同源适配服务提供静态页面与 `/api`；浏览器发送用户填写的 Gate Key，不包含官方 NAI Key，也不直接请求 NovelAI。

## 本地开发

需要 Node.js 22+。先启动可访问的工作台 Gate 适配服务，再运行：

```sh
npm ci
npm run dev
```

Vite 将 `/api` 转发到 `http://127.0.0.1:8787`。生产静态文件通过 `npm run build` 生成到 `dist/`；`Dockerfile.gate` 在镜像构建期间执行该步骤，不依赖预先生成的 `dist`。

## Gate 模式

- 绘图、图生图、重绘、支持模型的 Vibe/精准参考、放大、导演工具和浏览器批量任务通过同源 API 交给 Gate 适配服务。
- 批量任务在页面内串行执行。刷新或关闭页面后不能恢复在途请求；结果不确定时停止，不自动重放。
- 作品、提示词、参考图和草稿保存在当前浏览器的 IndexedDB。服务端不提供共享图库或长期结果存储；站点地址和 Gate Key 会隔离本地数据空间。
- 报价是客户端/适配层估算，不是 Gate 的最终授权或扣费结果。

页面按 Gate 声明的模型能力启用控件；具体操作仍受 Gate 版本、账户订阅和上游限制影响。完整的运行与测试步骤见[开发说明](../docs/DEVELOPMENT.md)。
